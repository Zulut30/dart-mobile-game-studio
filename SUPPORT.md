# Support

Use the channel that matches the request:

- **Questions and ideas:** GitHub Discussions.
- **Reproducible defects:** a Bug report issue.
- **Feature proposals:** a Feature request issue.
- **Security concerns:** private vulnerability reporting described in
  [SECURITY.md](SECURITY.md).

Include the host tool (Codex, Claude Code, or Cursor), operating system,
Flutter/Dart versions, project rendering mode, and the exact command output.
Please remove tokens, signing material, personal data, and private assets before
posting.
