# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, gender
identity and expression, level of experience, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique code and decisions, not people.
- Accept responsibility, apologize, and learn from mistakes.
- Protect private data, credentials, and unpublished assets.
- Prioritize the safety and accessibility of children and other vulnerable users.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized content, publishing
private information, deliberate disruption, and copyright infringement are not
acceptable in project spaces.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile
or private vulnerability reporting when confidentiality is required. Maintainers
may edit or remove contributions and may temporarily or permanently restrict
participation when behavior is harmful.

This policy is adapted from the Contributor Covenant, version 2.1.
