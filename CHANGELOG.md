# Changelog

All notable changes to Dart Mobile Game Studio are documented here. The project
uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-12

### Added

- Production-ready `dart-mobile-game-studio` skill for Flutter widgets, Flame,
  and hybrid 2D mobile games.
- Fourteen specialist agent profiles for Codex, Claude Code, and Cursor with
  tiered model routing.
- Twenty-one task workflows, nine genre templates, twelve review checklists,
  and compiler-backed model/renderer templates.
- AI context pack, task router with a 52-case RU/EN evaluation corpus,
  self-review loop, project discovery, documentation and design doctors,
  safe automation helpers, and release checks.
- Buildable `memory_match` and `endless_runner` reference games with pure-Dart
  cores, accessibility tests, responsive layouts, and lifecycle handling.
- Cross-platform CI plus Android AAB and unsigned iOS release canaries.
- Safe installer, deterministic release packaging, and clean-install smoke test.

### Security and policy

- Privacy-first and kids-safe defaults, minimal dependencies, asset licensing
  checks, deterministic RNG, and explicit store-compliance risk reporting.
