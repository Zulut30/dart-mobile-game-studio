# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| Pre-1.0 snapshots | No |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include affected files, impact, reproduction steps, and a proposed fix when
   available.

Do not open a public issue for secrets, command-injection paths, unsafe
installer behavior, destructive automation, privacy leaks, or supply-chain
problems. We aim to acknowledge a report within seven days and will publish a
coordinated advisory when a fix is available.

The project never requests signing certificates, provisioning profiles,
keystores, API keys, child data, or store credentials in issues or chat.
